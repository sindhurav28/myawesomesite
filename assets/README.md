# 🖼️ Silicon Valley easter-egg images

Drop the real show images here and they'll appear automatically when you click
the matching hidden egg in the world. Until a file exists, a friendly emoji
placeholder shows instead.

Use these exact file names:

| Egg (click it in the valley) | File to add here      |
|------------------------------|-----------------------|
| 🧥 Jared's jacket            | `jacket.jpg`          |
| 🖼️ The painting/mural        | `painting.jpg`        |
| 🍾 Tres Commas bottle        | `tres-commas.jpg`     |

Notes:
- `.jpg`, `.png`, etc. all work — just match the name in the table (rename your
  file to `jacket.jpg`, etc.). If you prefer `.png`, tell me and I'll switch the
  paths in `js/world.js`.
- Keep them reasonably small (a few hundred KB) so the page stays fast.
