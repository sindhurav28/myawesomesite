# 🏢 Company logos

Drop logo images here and they'll appear on the matching building in the valley.
Until a file exists, the building shows the company name as text.

Use these exact file names (PNG with a transparent background works best):

`hooli.png` · `facebook.png` · `oracle.png` · `youtube.png` · `google.png` ·
`twitter.png` · `netflix.png` · `apple.png` · `whatsapp.png` · `uber.png` ·
`lyft.png` · `amazon.png`

Tip: small, wide logos (a few hundred px) look best on the little sign boards.
Want `.svg` or `.jpg` instead of `.png`? Tell me and I'll switch the paths.
